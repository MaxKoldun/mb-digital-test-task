###### Умови тестового

Онлайн-платформа курсів

###### Дизайн:

Робиться на ваш розсуд, але щоб це було більше реальне до сприйняття.
Функціональні вимоги:

###### Список курсів

- Реалізувати компонент CourseList, який отримує масив курсів через props або mock API (GET /courses)
- Кожен курс містить: id, title, description, videoUrl (HLS/MP4), price
- Користувач бачить список курсів у вигляді карток з кнопкою Купити біля кожного курсу

###### Відео 
- При кліку на курс відкривається modal або inline-компонент з HTML5-тегом <video>
- Відео відтворюється з переданого videoUrl

###### Mock оплата

- При кліку на кнопку Купити викликається mock-функція handlePurchase(courseId)
- Функція повертає результат або помилку
- Куплені курси зберігаються у state

###### Управління станом

- Використати Redux або Redux Toolkit
- Зберігати список куплених курсів та стан поточного відео, яке відтворюється

###### Форма та валідація

- Реалізувати просту форму реєстрації / логіну з полями Email та пароль
- Користувача зберігати в localStorage
- Реалізувати логаут, який буде видаляти користувача з localStorage

###### Валідація

- Email має бути у правильному форматі
- пароль - мінімум 6 символів, одна велика літера, одна маленька і один спецсимвол

###### Технічні вимоги:

- React + TypeScript
- Redux або Redux Toolkit
- HTML5 <video> для відтворення
- Mock API (локальний масив або fetch із затримкою)
- Стилізація за вашим бажанням (CSS, SCSS, Emotion) + базова адаптивність
- Використання Git (історія комітів)
